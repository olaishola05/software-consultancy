# Landing Page PRD — [BRAND NAME]

## 1. Objective

A single-page, conversion-focused landing page for a software consultancy. The page targets startup founders and SME owners and drives them to book a free consultation call. This is not a multi-service brochure site. One audience, one primary action.

**Primary CTA:** Book a Free Consultation (Calendly link)
**Secondary CTA:** Phone number or contact form, placed near the footer, for visitors who prefer not to book directly.

---

## 2. Tech Stack

- Framework: Next.js
- Styling: Tailwind CSS
- UI Components: Shadcn UI
- Deployment: Vercel

---

## 3. Target Audience

Startup founders and SME owners who need production-grade software (MVPs, SaaS platforms, FinTech solutions) built by a small, senior, full-stack-capable team. Not enterprise, not government, not local brick-and-mortar service businesses.

## 5. Page Sections

### Hero
- Headline: positions the company as a technology partner for startups/SMEs, not "just another dev shop."
- Subheadline: what is built (web, mobile, SaaS, FinTech) and who it's for.
- Primary CTA button linking to Calendly.
- Short trust line beneath the CTA reducing booking friction (e.g., no sales pitch, just a real conversation).

### Problem / Positioning
- Names the pain point: unreliable freelancers, agencies that don't understand the business side, or being too early-stage for a big agency.
- States the value proposition: a technology partner, not just a coder.

### Services (4 max)
1. MVP & Product Development
2. SaaS Platforms
3. FinTech Solutions
4. Cloud & DevOps / Technical Consulting

Each service gets one outcome-focused sentence, not a feature list.

### Case Studies (4 featured)
1. FinTech project
2. EdTech project
3. E-Commerce project
4. Internal tooling / dashboard project

Each formatted as: Problem → Solution → Outcome.

### Social Proof
- Testimonial cards (placeholder content until real client quotes are available).
- Trust-signal row showing tools/platforms used (Stripe, Paystack, Vercel, etc.) as supporting credibility.

### How We Work
Simplified 4-step process:
1. Discovery Call
2. Proposal & Scope
3. Build & Check-ins
4. Launch & Support

### Pricing
- MVP Package: Starting from $5,000
- Startup SaaS Package: Starting from $8,000
- Enterprise: Custom quote, book a call

### FAQ
Suggested starting questions:
- How long does a typical project take?
- Do you work with non-technical founders?
- What if I only have an idea, not a full spec?
- Do you offer support after launch?

### Final CTA
Repeat of the primary Calendly CTA, with the phone/form fallback option included here as well.
